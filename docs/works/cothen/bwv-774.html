Invention No. 3 in D major

BWV 774 · D major · 1723
documented
Forces — Keyboard
Recommended recording — see set card  ·  Recordings Shelf
Score — IMSLP (free score)

Core idea. D-major brightness in compound-meter swing: a lilting figure that rides long sequences (the same idea restated a step higher or lower — Bach's basic engine of momentum) toward each cadence. The happiest of the fifteen.

Study. Bracket the sequences: where does each begin, how many rungs does the ladder have, where does it land? Sequence-hearing is the single most transferable skill the Inventions teach — the concertos (Brandenburgs included) run on exactly this ladder-work at orchestra scale.
